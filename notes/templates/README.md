# Engineering Templates

Reusable formats for any project.

## Files

- `dev-log-template.mdx`: 목적, 스케치, 계획, 이슈, 완성된 흐름, 개선점 순서의 개발 로그.
- `adr-template.md`: Architecture Decision Record for major technical decisions.
- `weekly-engineering-template.md`: Weekly status update.
- `release-note-template.md`: Release summary and rollout notes.

## Suggested Workflow

1. Write a `dev-log` for each meaningful implementation step.
2. Create an `ADR` when a decision changes architecture, stack, or long-term cost.
3. Publish a `weekly report` to track delivery and risk.
4. Publish `release notes` for each tagged release.

## Naming Convention

- Logs: `<projectname>-log1`, `<projectname>-log2`, ...
- ADRs: `ADR-0001`, `ADR-0002`, ...
- Releases: `v0.1.0`, `v0.2.0`, ...
