## Project Overview

A personal portfolio website built to showcase my development projects and skills. This responsive web application features a clean, modern design that works seamlessly across all devices.

## Stacks

- Next.js 14, TypeScript, TailwindCSS

## What I Built

- Responsive portfolio website with project showcase
- Interactive image slider component for project galleries
- Clean navigation and project filtering system
- Optimized performance with Next.js Image component

## Key Features

- **Responsive Design** - Works on mobile, tablet, and desktop
- **Image Slider** - Smooth transitions between project images
- **Project Gallery** - Clean presentation of development work
- **Fast Loading** - Optimized images and efficient code splitting
- **Modern UI** - Clean interface with smooth animations

## Development Highlights

- Built custom reusable components including the image slider
- Implemented responsive design with mobile-first approach
- Used Next.js Image optimization for better performance
- Applied TypeScript for type safety and better code quality

This portfolio demonstrates my ability to build modern web applications using current technologies and best practices.
