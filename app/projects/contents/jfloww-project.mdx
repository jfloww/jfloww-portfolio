# Overview

A personal portfolio website to showcase development projects, skills, and visual work with a clean, responsive layout. The goal was to make updates easy while keeping the design consistent.

## Tech Stack

- Next.js
- TypeScript
- TailwindCSS

## Process

### 1. Goal and Scope

Create a lightweight portfolio site that can scale as new projects are added without layout rework.

### 2. Approach

Use MDX for content, a simple list/detail structure, and reusable layout components to keep updates easy.

### 3. Implementation

- Project list with cover images and metadata
- Detail pages with optional image slider
- Shared layout components for consistency

## Results

Fast-loading, consistent pages with a clean visual hierarchy and simple content maintenance.

## Visuals / Gallery

This project uses the top image slider to present the gallery.

## Notes

- A flexible content pipeline makes updates quick and consistent
- Reusable templates reduce design drift between projects
